# 📖 LibraSmart — Smart Book Management System

> *"Not all those who wander are lost — but all those who read, are always found."*
> — LibraSmart Philosophy

**LibraSmart** is a modern, intelligent library management system built as a DBMS project. It brings the timeless love of reading into the digital age — making library management effortless for librarians and readers alike.

🌐 **Live Demo:** [LibraSmart Website](https://umairhabib971-a.github.io/DBMS_SMART_BOOK_MANAGEMENT_PROJECT/)

---

## 🎯 Project Objectives

- Design and implement a **fully functional relational database** for a real-world library management scenario
- Apply core **DBMS concepts** including normalization, relational schema design, and SQL querying
- Build a **role-based system** supporting Members, Librarians, and Administrators with tailored access
- Automate library operations such as **borrowing, returning, fine calculation, and notifications**
- Provide a clean, accessible **web interface** that interacts with the backend database in real time
- Demonstrate the integration of a **frontend + backend + database** stack in a production-grade project

---

## 🌟 Website Features

### 👤 Member Features
- **User Registration & Login** — Secure account creation with session-based authentication
- **Book Catalog** — Browse, search, and filter thousands of books by genre, author, or availability
- **One-Click Borrowing** — Borrow available books instantly with automatic due-date assignment
- **Online Book Renewal** — Extend loan periods once per book (adds 14 days) without visiting a desk
- **My Books Dashboard** — View currently borrowed books, due dates, and borrowing history
- **Smart Notifications** — Automated reminders for upcoming and overdue due dates

### 🛡️ Admin & Librarian Features
- **Admin Panel** — Full control over users, books, inventory, and system settings
- **Analytics Dashboard** — Real-time reports on borrowing trends, popular books, and inventory status
- **Fine Management** — Automatic overdue fine calculation (PKR 2/day/book) with payment tracking
- **Member Management** — View, activate, suspend, or manage member accounts and borrowing limits
- **Book Inventory Control** — Add, edit, remove, or update book availability in real time

### 🔒 Security Features
- Role-based access control (Member / Librarian / Admin)
- PHP session management for secure login states
- Password hashing and encrypted database connections
- HTTPS/SSL deployment
